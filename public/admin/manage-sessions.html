Pairing Code

------

Cara gunakan Pairing Code:

  1. Buka WhatsApp di HP Anda
  2. Tap Menu (⋮) atau Settings
  3. Pilih Perangkat Tertaut
  4. Tap Tautkan dengan Nomor Telepon
